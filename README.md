# Jae Seong Lee

Backend engineer in Seoul. Native Korean and native-level English (about 15 years in the US). B.S. in Computer Science, The University of Texas at Austin.

## Building now

**[EasyGongsi](https://www.easygongsi.com)** turns filings on DART, Korea's electronic corporate disclosure system, into plain-language summaries, key numbers, and alerts for Korean retail investors. Built and run alone: a Next.js web app on Vercel, a Node.js worker on AWS EC2, and PostgreSQL. Claude Code speeds up implementation; design, code review, operations, and incident response are my own. The code is private; the write-up, **[easygongsi-architecture](https://github.com/jaelee0409/easygongsi-architecture)**, covers the architecture, key decisions, and known limitations.
