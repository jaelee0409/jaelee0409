# Jae Seong Lee

Backend engineer in Seoul. Native Korean and native-level English (about 15 years in the US). B.S. in Computer Science, The University of Texas at Austin.

## Building now

[EasyGongsi](https://www.easygongsi.com) turns filings on DART, Korea's electronic corporate disclosure system, into plain-language summaries, extracted figures, and alerts for Korean retail investors. I built it and run it alone: a Next.js web app on Vercel, a Node.js worker on AWS EC2, and PostgreSQL. Claude Code speeds up implementation; design, code review, operations, and incident response are my own. The code is private. The write-up, [easygongsi-architecture](https://github.com/jaelee0409/easygongsi-architecture), covers the architecture, the design decisions, and the known limitations.
